Design language

The approved visual reference for y-agent host and module UI. Solarized tokens, one radius, one floating elevation, and the host-owned checkbox and field treatments are the system in use.

Scope. Solarized is the only supported theme family. Semantic accents remain fixed; the neutral scale reverses between polarities. All samples below respond to the polarity switch.

Checkbox treatment

Host class .y-check: a 14px token-aware square with a 3px corner radius (the only non-4px control corner). Unchecked uses the canvas and muted border; checked becomes blue with an inset canvas mark; keyboard focus receives a blue halo; disabled is opacity:.55. Browser-native checkbox appearance is not part of the design language.

Surface rules

One radius token: 4px (rounded), with rounded-full kept for genuinely round objects (dots, avatars, toggle tracks/knobs, progress bars, circular icon buttons, count pills). Inputs use host class .y-field for quieter base02/base03 fill, translucent base01 border, and blue focus halo. Non-floating surfaces have borders only. Menus, dialogs, popovers, tooltips, drawers, toasts, and FABs use one shadow-float elevation.

Settled conventions

shipped in todo 3115

Checkbox: host class .y-check

One custom primitive for every type="checkbox" in host and module UI. Spec: appearance:none, 14px square, border-radius:3px, muted base01 border on base03 fill; hover raises the border; checked is blue with an inset base03 mark; :focus-visible draws a 2px blue outline at offset 2px; disabled is opacity:.55; cursor:not-allowed. Class name is append-only while older module versions remain rollback-reachable.

Radius: one 4px token, round objects stay round

Host and SDK register --radius: 4px; bare rounded resolves to it. Sized variants (rounded-sm|md|lg|xs) are not used. rounded-full remains for genuinely round objects: status dots, chart legend swatches, avatars/initials, routine toggle track and knob, progress bars/tracks, circular icon buttons and FABs, and count pills. Absolute 4px (not 0.25rem) because root font is 110%.

Elevation: one Solarized-aware shadow-float

Ordinary panels, cards, and rows stay border-defined with no elevation. Any layer floating above the document uses shadow-float: light 0 12px 28px rgb(7 54 66 / 16%), dark 0 12px 28px rgb(0 0 0 / 30%). The Tailwind theme key holds a var indirection so the shadow flips with polarity at runtime. Host class .y-field owns input fill/border/focus only; size and padding stay per-site utilities.
